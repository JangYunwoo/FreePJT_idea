# PINCH TOWER — 손동작 블록 쌓기

웹캠 앞에서 엄지와 검지를 붙여 오른쪽 대기 칸의 블록을 집고, 왼쪽 쌓기 공간에 놓는 웹 게임 프로토타입입니다. 카메라로 인식한 손의 가로·세로 위치가 블록 위치에 그대로 반영됩니다. 집은 동안 A/D 키로 블록을 90도씩 회전할 수 있습니다. 원하는 높이에서 놓으면 그 자리부터 중력에 따라 떨어져 탑에 부딪히고, 균형에 따라 기울거나 무너집니다. 손으로 더 쉽게 겨냥하도록 블록 한 칸을 36px로 키웠고, 중앙 바닥은 네 칸(144px) 너비입니다. 탑이 높아지면 화면이 부드럽게 위로 따라가므로, 화면을 벗어난 높이에도 계속 쌓을 수 있습니다. 양쪽으로 떨어진 블록은 바닥 아래로 완전히 내려간 뒤 제거됩니다. 처음 화면에서 개인전 또는 방 코드 경쟁전을 선택할 수 있습니다.

## 실행

Node.js가 설치되어 있다면 이 폴더에서 아래 한 줄로 실행합니다. 패키지 설치는 필요 없습니다. 경쟁전 방 서버도 함께 실행됩니다.

```bash
node server.mjs
```

브라우저에서 `http://localhost:8000`을 열고 개인전 또는 경쟁전을 고르세요. 모델과 라이브러리를 CDN에서 가져오므로 첫 실행에는 인터넷 연결이 필요합니다. 카메라 권한을 허용해야 합니다. `file://`로 HTML 파일을 직접 열면 카메라가 동작하지 않을 수 있습니다.

개인전은 **개인전 → 카메라/마우스 설정 및 조작 테스트 → 게임 시작** 순서로 진행합니다. 설정 화면의 버튼 하나로 카메라와 마우스 모드를 전환하며, 같은 화면에서 가운데 2×2 블록 하나를 집어 움직여볼 수 있습니다. 테스트 블록은 중력 없이 놓은 자리에 그대로 남으며, 실제 게임 점수와 무관합니다. 시작 후에는 게임 맵만 표시되며, 설정을 바꾸려면 모드 선택으로 돌아가 다시 들어가세요.

개인전은 VS Code Live Server나 `cd dist` 후 `python -m http.server 8000`으로도 실행할 수 있습니다. **경쟁전은 `node server.mjs` 방 서버가 반드시 필요합니다.** 다른 PC에서 카메라를 사용하려면 HTTPS 주소가 필요합니다. 단순히 같은 와이파이의 HTTP 주소를 공유하면 상대 브라우저에서 카메라 사용이 차단될 수 있습니다.

## 경쟁전

1. 첫 화면에서 **경쟁전**을 선택하고 이름을 입력합니다.
2. 한 명이 **새 방 만들기**를 눌러 6자리 방 코드나 초대 링크를 공유합니다. 다른 플레이어는 같은 서버 주소에서 코드를 입력해 참가합니다. 최대 6명입니다.
3. 대기실의 **카메라 설정**을 누르면 ‘조작 방법을 선택하세요’ 화면에서 손 인식 또는 마우스 조작을 선택하고, 가운데 2×2 블록 하나로 조작을 시험할 수 있습니다. 테스트 블록은 놓은 자리에 남고 **가운데로** 버튼으로 위치를 초기화할 수 있습니다. 설정을 마친 뒤 대기실로 돌아와 각자 **준비 완료**를 누릅니다.
4. 2명 이상 모이고 모두 준비하면 방장이 시작합니다. 참가자는 동시에 각자의 12개 블록을 쌓습니다.
5. 게임 맵 왼쪽에서 상대의 탑과 진행 상황을 작은 화면으로 볼 수 있습니다. 웹캠 영상은 전송하지 않고 블록 위치·각도만 공유합니다.
6. 모두 12개를 놓은 뒤 잠깐 정착 시간을 거쳐 **탑 높이가 가장 높은 사람**이 이깁니다. 높이가 같으면 남은 블록 수로 결정하고, 그것도 같으면 무승부입니다.
7. 결과를 확인한 뒤 같은 방 코드의 대기실로 자동 복귀합니다. **대기실로 돌아가기** 버튼을 누르면 바로 복귀할 수도 있습니다. 다음 경기를 시작하려면 다시 모두 준비 완료를 눌러야 합니다.

방 데이터는 서버 메모리에만 있으며 서버를 재시작하면 사라집니다. 새로고침한 탭은 같은 방으로 재접속을 시도합니다. 한동안 연결되지 않은 참가자는 방에서 정리됩니다.

### GitHub Pages로 공개할 때

GitHub Pages는 정적 파일만 제공하므로, **이 저장소를 Pages에 올리는 것만으로 경쟁전은 작동하지 않습니다.** `server.mjs`를 별도의 HTTPS Node.js 서버에 배포하고, `dist/config.js`의 `PINCH_TOWER_API_BASE`를 그 서버 주소로 바꿔야 합니다. 서버에는 `PINCH_TOWER_ORIGIN` 환경 변수로 Pages 사이트의 정확한 출처(예: `https://<username>.github.io`)를 지정해야 합니다. 개인전은 별도 방 서버 없이 Pages에서 실행할 수 있습니다.

## 조작

1. 오른쪽 `READY TO GRAB` 칸 위로 손가락을 가져갑니다.
2. 엄지와 검지를 붙이면 블록을 집습니다.
3. 왼쪽 쌓기 공간에서 손을 좌우·위아래로 움직여 블록의 위치와 낙하 높이를 직접 정합니다. 잡은 동안 `A`는 반시계, `D`는 시계 방향으로 90도씩 회전합니다. 손가락을 벌리면 그 방향 그대로 블록이 떨어집니다. 평소에는 자동 높이 보정이나 착지 가이드가 없습니다. 다만 이미 쌓인 블록이나 바닥과 겹친 상태에서 놓으면 새 블록이 가까운 빈자리로 짧게 밀려난 뒤 떨어집니다.

카메라가 없어도 **마우스로 테스트** 모드에서 오른쪽 블록을 클릭해 드래그하고, 잡고 있는 동안 `A`/`D`로 회전한 뒤 왼쪽에서 버튼을 놓아 게임 흐름을 확인할 수 있습니다. 총 12개의 블록을 쌓으면 라운드가 끝납니다. 오른쪽 위 `↻` 버튼으로 초기화할 수 있습니다.
`PLACED`는 놓은 블록의 누적 수이고, 최종 결과에는 바닥 밖으로 떨어지지 않고 남은 블록 수가 표시됩니다.

## 사용한 오픈소스

- [MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js) — 웹캠 영상에서 손의 21개 랜드마크를 추출합니다. 집기/놓기 판정은 엄지·검지 끝 사이 거리와 손바닥 폭으로 이 프로젝트에서 직접 구현했습니다. [Apache 2.0 라이선스](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE).
- [Matter.js](https://brm.io/matter-js/) — 블록의 중력, 충돌, 마찰과 쌓임을 계산합니다. [MIT 라이선스](https://github.com/liabru/matter-js/blob/master/LICENSE).

현재는 MediaPipe의 사전학습 손 추적 모델을 활용하는 프로토타입입니다. 자체 학습한 동작 분류 모델은 아직 없으며, 카메라 영상은 게임 화면에서 직접 손 좌표를 계산하는 데 사용됩니다. CDN 라이브러리와 모델 다운로드, MediaPipe의 사용 지표 처리에 관한 사항은 배포 전에 별도 검토가 필요합니다.
